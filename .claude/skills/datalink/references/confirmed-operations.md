## 工作流设计

确认：表单设计顶栏的「工作流设计」打开 `#/form/processDesign`，仍是当前表单。2026-11-12 在「表单001」上，这一页一开始只有按钮「使用表单工作流」，说明是开启后设置流转条件。点了这个按钮，进入设计器，标题是「表单001 (V1) 草稿」。没有点「启用」，也没有点工作流的「保存」。

设计器左侧可拖出三种节点：普通节点、审批节点、子流程。提示是拖到画布上再连线。默认画布只有「工作流开始节点」和「工作流结束节点」。为了看属性，曾拖过审批、普通、子流程各一个，看完用撤销去掉了，画布回到只有开始和结束。

工作流属性里：允许发起人/处理人催办默认关；允许查看工作流日志和流转图默认开；允许分享链接默认开。还有「关闭工作流」。这次点了取消。

开始节点属性分节点名称、字段权限、更多设置。名称默认「工作流开始节点」，节点 ID 是 node0。字段权限有可编辑、可见、简报三列，当时名称、数量、日期、状态都没勾。更多设置里的操作有提交、保存、转交、撤回、挂起、结束工作流，还有智能助手。日志可以分别限制工作流卡片、数据视图实例详情、自定义报告审批意见是否可查看所有日志。

结束节点没有这些配置。说明写着：它只是出口，数据转到这里表示工作流结束，不再产生待办。可以配合流转条件，让中间节点在满足条件时直接结束。

审批节点：要添加负责人，可启用抄送、密送。审批规则默认「或签（任意负责人通过即进入下一节点）」，另一项是「会签（所有负责人通过进入下一节点）」。更多设置里处理意见是文本意见，可选禁用、选填、必填。操作有通过、保存、拒绝、转交、撤回、挂起、结束工作流。

普通节点：同样有负责人、抄送、密送。流转规则默认「任意负责人提交后进入下一节点」。

子流程：要选子流程表单、子流程发起人，并配数据传递规则。流转规则当时是「子流程结束后进入下一个节点」，另有「子流程发起后自动提交」。

开始和结束默认没有连线。从一个节点边缘的连接点拖到另一个节点，会生成连接线。键盘 Delete 和 Backspace 删不掉线，也删不掉节点。左上角撤销可以去掉刚拖上的节点和刚连上的线。后来为了启用，开始和结束重新连上了，这条线还在。

点中连接线出现「连接线属性」。默认是「自定义数据流转条件」，也可以改成「使用 else 流转条件」。自定义设置里，条件可以要求全部满足，或任意一个满足。添加条件时先从下拉里选字段，这次能选名称、数量、日期、状态、提交人、更新人、提交时间、更新时间，旁边标着时区 UTC+08:00。选了名称之后，比较默认是「等于」。比较还可以换成：不等于、等于任意一个、不等于任意一个、包含、不包含、为空、不为空。值的旁边有个开关，关掉时直接填值，打开后变成「公式」。

连接线还可以改成「使用 else 流转条件」。这时的说明是：数据不满足同级其他流转条件时，走进这条线下面的节点。看完已改回自定义。

审批节点可以「启用抄送」「启用密送」。打开之后，抄送和密送各自再出现一个「添加负责人」，选人方式和负责人相同。处理意见默认是「禁用」，也可以改成选填或必填。操作权限里，通过、保存、拒绝默认是按下的；转交、撤回、挂起、结束工作流默认没按下。

节点更多设置里的「智能助手」打开后可以设唤醒时间。默认是自定义时间 1 分钟，也可以选工作流到达节点之后若干分钟。下面有「添加自动处理」，按钮是保存。这次没有保存。

## 字段

26 个字段都是点左侧加上、打开属性面板、再按删除流程去掉的。公式编辑器、跨表取值弹层、水印设置、流水号每一段规则、按钮每一款样式、语音录入勾上之后的语言列表，没有点进去。

### 多数字段都有的

基础属性：

- 标题和输入提示是富文本，字体默认微软雅黑 14px。可隐藏标题。提示可以改成问号图标，默认不改。
- 标题和输入框的布局分 PC 端、移动端。两套之间的差别这次没对照。
- 必填默认关。可见、可编辑默认开。例外见各字段。
- 字段占比默认 100%，可选 25%、50%、75%、100%，或自定义 5%～100%。左间距默认无，可选 25%、50%、75%。富文本的占比只有 50%、75%、100%。

高级属性：

- 字段 ID 自动生成，不可改。
- 字段系统名称默认空，只允许字符、数字和 `-_()./`，当时输入框是灰的。
- 「允许用户界面修改」「允许用户界面显示」默认开。前者只在这个人有可编辑权限时生效，后者只在有可见权限时生效。

数据流水线出现在这些字段的高级属性里：单行文本、多行文本、数字、日期时间、单选、多选、单选下拉、多选下拉、图片、附件、视频音频、手写涂鸦、富文本、成员单选、成员多选。

- 触发场景：字段取值或字段校验。默认字段取值。
- 触发方式：焦点触发、按钮触发、不触发。默认按钮触发。
- 按钮名称默认「查询」。提示语默认「查询中，请稍候」。
- 返回多条时：用户选择或直接写入。默认用户选择。
- 流水线写回：保留已有数据或清空已有数据。默认保留。
- 表格数据写入：覆盖写入或清空写入。默认覆盖。

按钮、分割线、定位、数据引用、数据关联、表格、分组、页签、流水号、折叠面板、iFrame 没有扫到这五个下拉。

### 基础字段

**单行文本**

画布是一个输入框，提示「请输入内容」。格式默认无，可选中国身份证、邮箱、URL 链接、文本超链接。加密是单独的开关，默认关；关掉已开启的加密时，页面警告已填数据会解密。取值可选初始值、跨表取值、公式。最大字符数默认 4000，可显示字数。不允许重复值默认关。字段类型可改成多行文本。高级里还有扫码输入（可再允许修改扫码结果）和语音录入。语音没勾选时，语言下拉是灰的，选项没读到。

**多行文本**

提示「请输入内容」。默认 3 行，可高度自适应。最大 4000 字。取值是初始值、跨表取值、公式。没有格式和加密。字段类型下拉是灰的，不能从这里改类型。

**数字**

提示「请输入数字」。显示格式默认数值，还可百分比、经度-小数、纬度-小数。允许小数默认开，小数位数默认 2。限定数值范围、显示千分符默认关。范围输入里读到 1 和 10000，是不是默认上下限还没复核。取值是初始值、跨表取值、公式。可禁止重复。字段类型可改回单行文本。

**日期时间**

提示「请选择完整日期」。显示格式默认「年/月/日 时:分:秒」。其余格式：年、年/月、年/月/日、日/月/年、日/月、月/日、年/月/日 时:分、日/月/年 时:分、日/月/年 时:分:秒、日/月 时:分、日/月 时:分:秒、月/日 时:分、月/日 时:分:秒。可限定起止时间，默认关。取值是初始值、跨表取值、公式。字段类型不能改。

**单选**

默认选项 1、选项 2、选项 3。可逐条改、批量编辑、添加选项、添加「其他」。彩色开关默认关。排列默认横向，也可纵向。自动换行默认关。有跨表取值和公式的入口，不是「取值」下拉。字段类型可改成单行文本或单选下拉。

**多选**

选项、彩色、排列与单选同一套。另有「允许用户填写时增加其他选项」，默认关。可限制最多勾选几个，输入框里是 1。不允许重复值是灰的。字段类型可改成单行文本或多选下拉。

**单选下拉**

画布提示「请选择」。选项来源默认自定义，也可跨表取值或公式。默认同三个选项，可加「其他」。高级里「展示最近选择」默认开。字段类型可改成单行文本。

**多选下拉**

与单选下拉同一套，另有填写时加选项，以及最多勾选数。不允许重复值是灰的。「展示最近选择」默认开。字段类型可改成单行文本。

**按钮**

默认文案「按钮」。面板上有按钮样式，每一款没逐个点开。功能有「多功能」开关，打开后可选打开表单、打开 URL、数据流水线。没有必填。

**分割线**

一条线。线型当时是 solid，可设背景色。样式下拉只读到「分割线」这一项。只有可见，没有可编辑，也没有必填。

### 增强字段

**图片**

上传。页面写明华为内网上传的文件不能在外网查看和下载。允许压缩默认开。仅允许拍照上传默认关。最大张数默认开，数量是 1。加密、水印默认关。取值下拉是灰的，旁边仍有跨表取值和公式入口。水印字段设置没点开。

**附件**

文案「点击上传附件」，同样有内网上传提示。最大数量默认 1。类型默认带 .doc，列表还有 docx、xls、xlsx、ppt、pptx、rar、zip、txt、bmp、gif、jpg、eml、msg、pdf、png、tif、tiff、kml、xlsm、mp4、mov、jpeg、webm、arm、ogg、ogv、acc、mp3、wav、avi、csv、cpi、rmvb、kmz、dwg、m4a、xml、nic、stl、vsdx、webp、dll、gds、html、htm、mif、mid、skp、heif、md。大小默认 0～100 MB。文件名规则默认无，也可文件名精确匹配。加密默认关。

**视频音频**

格式默认视频，可改音频。按钮文案默认「上传视频」。类型默认 .mp4，可选 mp4、mov、webm、mp3。可限制只能移动端录制后上传，默认关。最大数量默认 1。内网上传提示与图片相同。

**定位**

画布提示要在移动端打开表单才能获取位置，按钮叫「获取位置」。可设允许微调的米数、限定定位范围，两项默认关。有定位字段设置，没点开。

**数据引用**

按钮默认「引用数据」。要选引用应用、引用表单、引用字段，可加过滤条件。当时应用下拉里只有「应用001」。允许新增被引用表单的数据，默认开。引用字段设置没点开。

**数据关联**

要选关联应用、关联表单、关联字段，可加过滤条件。允许新增、允许编辑关联表单数据，默认都关。这个字段自己的可编辑默认关。当时应用下拉里只有「应用001」。

**表格**

空表提示从左侧把字段拖进表格。取值只有初始值和跨表取值，没有公式。移动端可展开最后一条、全部展开或全部收起。显示方向默认纵向平铺，也可横向表格。可让移动端突出显示选中行，默认关。PC 可冻结前若干列，默认关。每页行数默认 20，可选 5、10、20、50、100。操作列默认有新增、删除已有记录、编辑已有记录。操作列宽 114，右侧边栏宽 425。允许自适应默认关。高级里，界面新增/删除、导入/导出、空白时展示首行，默认都开。

**分组**

容器，用来包住别的字段。默认展开。没有必填。

**页签**

默认选项 1、选项 2、选项 3，可再添加。每个页签里再放字段。

**流水号**

提交时自动生成，框内写「该字段在提交时自动生成」。规则从一段开始，用「添加」再加段。段内怎么配，没点开。没有必填。

**手写涂鸦**

画布是「添加涂鸦」。Web 端启用手写默认关。

**富文本**

空内容时显示「暂无内容」，带编辑栏，也有内网上传提示。取值只有初始值和跨表取值。默认展开是关的。不可编辑时可选保留原样式或不保留。

**成员单选**

按钮「选择成员」。显示方式默认弹框，也可下拉框。有选择范围、取值范围，范围弹层没点开。取值是初始值或跨表取值。可禁止重复。「展示最近选择」默认开。

**成员多选**

与成员单选同一套，另有最多选几个，框里是 1。不允许重复值是灰的。「展示最近选择」默认开。

**折叠面板**

容器。默认展开。面板上没扫到可见、可编辑、必填这三项。

**iFrame**

没配地址时画布显示「未配置嵌入链接」。填 iframe 地址，地址里可以插入本表字段。高度默认 400px。
